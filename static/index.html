02 / Problem & approach

Objects are only the beginning.

Traffic events depend on behavior over time, camera perspective, and road context—not just a bounding box in one frame.

The problem

Reviewing traffic video manually is slow. The prototype turns footage into candidate event intervals and visual evidence for human review. It separates learned object detection from explicit traffic rules so the source of each prediction can be inspected.

Models, data, and why

Component Choice and rationale
Object detector YOLO11n; a compact pretrained baseline for CPU inference.
Pretraining data COCO object categories. These weights do not directly classify traffic accidents.
Tracking ByteTrack; keeps object identities across sampled frames.
Event logic Explicit geometry and temporal thresholds; inspectable but camera-specific.
Risk Closest approach in image coordinates; optional and uncalibrated.

Install and start the local app

Download and extract the full project. Install Python 3.12 and FFmpeg, then open Terminal in the extracted folder. On macOS, install them with brew install python@3.12 ffmpeg. 

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-local.txt
python scripts/download_weights.py
python local.py

The local interface opens in your browser. See the included README for Linux CPU-only PyTorch installation and Windows through WSL2.
