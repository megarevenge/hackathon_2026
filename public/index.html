BEHIND THE BOXES

Built to be understood.

A transparent pipeline, with learned object detection and configurable event rules.

01 / DETECT

Find the road users.

Pretrained YOLO11n locates people, bicycles, motorcycles, cars, buses and trucks in sampled frames.

02 / TRACK

Follow the movement.

ByteTrack connects observations over time. Brief predictions keep the display readable, but never count as event evidence.

03 / INTERPRET

Read the scene.

Camera geometry and trajectory rules produce event intervals. Every result is inspectable and downloadable.

CURRENT CAPABILITIES

Ten configurable event rules.

Stopped vehicles, wrong-way driving, jaywalking, congestion, failure to yield, red-light and stop-line violations, solid-line crossing, illegal turns and illegal U-turns.

Each rule needs the corresponding camera configuration. An uncalibrated camera produces tracks without event claims.

TECHNICAL REPORT / LIMITATIONS

Evidence before confidence.

Occlusion, small objects, ID switches and inaccurate scene boundaries can create missed or false events. Risk is a bounded heuristic, not a calibrated accident probability.

Accident, near-miss, road-obstacle and fire/smoke classification are not yet implemented. Ground-truth accuracy remains unmeasured.
